# YouLift (protótipo)

Protótipo de candidato para o Desafio de Inovação do Programa de Estágio YouShop 2027.

O YouLift testa a oferta extra do checkout (order bump) sem arriscar a venda principal: a IA sugere a oferta conforme a origem do tráfego, um experimento controlado mede o que sobra por checkout iniciado, e uma trava pausa a oferta que derruba a conversão.

**Dados simulados. Sem conexão com sistemas da YouShop.** A conta da primeira tela reproduz os cenários hipotéticos de um artigo do blog da YouShop. As sugestões de oferta são textos gerados previamente por um modelo de linguagem; as regras e as contas rodam no navegador.

Interface construída com React e a biblioteca de componentes Astryx. Esta pasta contém a versão compilada.
